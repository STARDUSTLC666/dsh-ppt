# 课程包转课件（ppt_course_*）

把一个**视频课程文件夹**直接交给插件，自动拆解、提炼重点、生成一套精讲课件并配套留作业。

## 触发条件

用户给的是一个**课程文件夹**（里面有录屏讲解视频 + 每节课的作业素材压缩包），想要「课件 / 精讲 / 课程包 / 拆解 / 留作业」，而不是只给一个主题。此时走 `ppt_course_scan` → `ppt_course_build`，而不是 `ppt_lesson_create`。

## 四个工具

| 工具 | 用途 | 是否落盘 |
| --- | --- | --- |
| `ppt_course_scan` | 干跑扫描：分类视频/压缩包/文档/图片，给课程序号、每课时长、素材匹配猜测 | 否 |
| `ppt_course_build` | 一键出活：扫描→抽音轨→转写→分课→提炼→成稿（三件套+作业） | 是 |
| `ppt_course_voice` | 音色替换：从视频/ srt 生成配音（需 VoiceStudio 在跑） | 是 |
| `ppt_course_clean` | 去水印：ffmpeg 滤镜处理视频，输出新文件 | 是 |

## 流水线（build）

1. **扫描**：复用 scan 的分类，视频自然排序为课序，ffprobe 取时长。
2. **抽音轨 + 转写**：ffmpeg 抽 16k 单声道 wav → ASR 三级探测 → 带时间戳分段。
3. **分课**：按视频自然排序为课序；单视频多课时的，按静音切分。
4. **提炼**：用 `ctx.llm` 把每课转写提炼成结构化要点（核心概念、关键步骤、易错点、案例/示例、小结），每个要点带时间戳溯源；转写缺失/过短或没有 LLM 时降级为**提取式摘要**，不编造。
5. **成稿**：复用 `deck-lesson.mjs` 的教学结构与 `buildDeckAsync` 出三件套，页数按 mode 控制。
6. **作业**：每课一页作业 + 单独 `homework.md`（任务、素材、评分要点、提交要求）。
7. **素材融入**：`useMaterials=auto` 解压到 `_materials/<课序>/`，按文件名/序号匹配。
8. **可选配音**：`voice.enabled` 时生成 SRT 调 VoiceStudio `/dub/*`。
9. **可选去水印**：`watermark.enabled` 时用 ffmpeg 处理，产出到 `_clean/`。

## 产出目录结构（固定）

```
<outputDir>/<课程名>/
  00-课程总览.html/.pptx/.json  +  course-index.md
  第01课-<标题>/  <同名>.html/.pptx/.json + .lesson-plan.md + homework.md
  第02课-.../
  _transcripts/第01课.srt + .json
  _materials/第01课/...
  _voiced/第01课.m4a            （可选）
  _clean/第01课-无水印.mp4      （可选）
  build-report.md              （每步做了什么、跳过了什么、为什么）
```

## 模式对照（mode）

| mode | 含义 | 每课页数 |
| --- | --- | --- |
| `deep`（默认） | 精讲：概念拆解、分段讲解、示例、易错点、练习引导 | 15–25 |
| `quick` | 快速预览：核心结论 + 结构图 | 6–10 |
| `outline` | 纯大纲 | 3–5 |

## 素材匹配规则

- 压缩包名含数字 N 且存在第 N 课视频 → 匹配第 N 课。
- 否则压缩包名与某视频文件名（去扩展名）互相包含 → 匹配该课。
- 都不匹配 → `matchedLesson` 缺省，build 时按第 1 课处理并在报告里说明。

## 音色（voice）与去水印（clean）用法与限制

- **音色**：先探测 VoiceStudio（`http://127.0.0.1:3900/`，2s 超时）。在跑才走 `/dub/*`；没在跑**明确报「VoiceStudio 未运行，请先启动」**，绝不假装成功。macOS `say` 只用于试听，不冒充成品。
- **去水印**：`regions` 是**唯一可靠**方式；`auto:true` 只做候选探测（多帧差分），产出的是「候选」，必须让用户确认后再执行，不要声称自动识别一定准。`delogo` 是邻域插值修补，画面会有痕迹；纯遮挡用 `box` 最稳；`crop` 只支持单个区域。

## ASR 三级探测（重要）

按顺序尝试，任一可用即用；全不可用**明确报错并给出可选方案**，绝不允许伪造转写：

1. **VoiceStudio 本地转写（首选）**：`POST http://127.0.0.1:3900/v1/audio/transcriptions`，字段 `file` + `model=whisper-1` + `language=zh`。前提：应用正在运行。
2. **DSH 宿主 / asr.json**：读 `$DSH_HOME/asr.json`（默认 `~/.dsh/asr.json`），`baseUrl` + `key`（或 `keyEnv`）齐全才算可用。
3. **都不可用** → 中文报错，列出三条出路：启动 VoiceStudio / 在 DSH「视频分镜设置」填 ASR key / 把 asr.json 的 baseUrl 指向 `http://127.0.0.1:3900/v1`。

## 硬性约定

- **不编造课程内容**：提炼必须溯源到转写时间戳；转写质量差时降级为提取式摘要并标注。
- **优雅降级**：没有 LLM / 没有 STT / VoiceStudio 没开时，分别给出明确中文原因和可继续的部分，不整条流水线崩掉。
- **可中断、可续跑**：转写、解压产物落盘缓存，重跑不重复转写。
- **路径安全**：解压防 zip-slip（`../` 越界），单文件与总量上限，不写到输出目录之外。
- **中文报错**：错误里说清「哪一步、哪个文件、下一步怎么办」。
