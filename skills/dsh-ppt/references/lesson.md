# 一键课件 · 教学设计说明

`ppt_lesson_create` / `ppt_lesson_generate` 只做一件事：把「一个主题/一句话想法」变成一份**可编辑的教学设计结构骨架**，而不是替老师备课。它负责结构、节奏、活动与评价框架；真实知识点、案例与数据仍要老师/AI 填写。

## 工具选择

| 工具 | 落盘 | 用途 |
| --- | --- | --- |
| `ppt_lesson_create` | HTML + PPTX + JSON + 教案 Markdown | 只给一个主题，一次到位出成品 |
| `ppt_lesson_generate` | 不落盘，返回 slides | 先看/改教案结构，再交给 `ppt_create` |

两者共用同一套生成逻辑（`deck-lesson.mjs` 的 `generateLessonPlan`），不会出现两份实现。

## 7 种教学模式对照

| 模式 | id | 中文 | 典型时长 | 主活动 | 自动挑选的互动 |
| --- | --- | --- | --- | --- | --- |
| 讲座式 | `lecture` | 教师主导系统讲授 | 45 | 指导性练习 | 投票 / 测验 / 思考-配对-分享 |
| 工作坊 | `workshop` | 动手实践、边学边做 | 45 | 动手实战项目 | 动手实操 / 小组讨论 / 同伴互评 |
| 案例教学 | `caseStudy` | 真实案例、决策思维 | 45 | 案例分析与决策 | 案例分析 / 小组讨论 / 画廊漫步 |
| 实验课 | `lab` | 实验、观察、推导 | 45 | 实验操作与报告 | 动手实操 / 同伴互评 / 出口票 |
| 研讨会 | `seminar` | 小组讨论、深度探究 | 45 | 深度探究讨论 | 小组讨论 / 思考-配对-分享 / 画廊漫步 |
| 翻转课堂 | `flipped` | 课前自学、课内应用 | 45 | 应用工作坊 | 同伴互评 / 小组讨论 / 反思日志 |
| 微课 | `micro` | 聚焦单一知识点 | 15 | 快速练一练 | （不插概念间互动，靠主活动） |

`lessonType` 未传时按中英文关键词自动推断：实操/动手/练习/workshop/hands-on → `workshop`；案例/case → `caseStudy`；实验/lab → `lab`；研讨/讨论/seminar → `seminar`；翻转/flipped → `flipped`；微课/15分钟/短课/micro → `micro`；否则 `lecture`。

## 受众 × 布鲁姆分类学映射

| 受众 | id | 中文 | 布鲁姆层级 |
| --- | --- | --- | --- |
| 入门/零基础 | `beginner` | 新手 | Remember / Understand |
| 进阶/有基础 | `intermediate` | 有基础 | Understand / Apply / Analyze |
| 高阶/专业 | `advanced` | 专业 | Analyze / Evaluate / Create |
| 混合水平 | `mixed` | 混合 | Understand / Apply / Analyze |

学习目标的动词随受众层级变化（如入门用「列举/解释」，高阶用「评价/设计」），并写入每页讲稿与教案 Markdown。

## 10 类互动活动

投票、测验、思考-配对-分享、小组讨论、动手实操、案例分析、同伴互评、出口票/离场卡、反思日志、画廊漫步。按教学模式自动挑选，插入在核心概念之间，并作为主活动的分步环节。

## 完整教学闭环

封面 → 学习目标 → 课程议程 → 引入钩子 → 核心概念（含视觉建议）→ 示例/案例 → 主活动（分步）→ 形成性检查 → 总结 → 课后作业 → 结束页。每页带 `notes`（讲稿/主持提示）与 `timing`（分钟），各页 `timing` 之和精确等于 `duration`。

## 占位符约定（重要边界）

生成的是**教学结构骨架**，不是真实学科知识。所有需要真实内容的位置统一用显式占位符：

- 中文：`[待填写：…]`
- 英文：`[To fill: …]`

典型占位位置：示例/案例的背景、挑战、结果；评价题的选项与正确答案；总结的一句话精华；作业的资源链接；结束页的讲师邮箱/资源链接。

这些占位符会让 `ppt_check` 把课件判为「草稿」（`deliveryStatus: draft`）——这是**有意为之**：未填完的内容不能作为成品交付。交付前请：

1. 用 `ppt_edit` 逐页把占位符替换为真实、可核实的内容；
2. 或把 `topic` 换成本课真实材料后重新生成；
3. 用 `ppt_check` 复检，确认不再有未填占位符，再说明可交付。

禁止编造具体数据、案例结果、百分比、人名、史实。不要把「生成了骨架」说成「已完成课件内容」。

## 确定性

以「主题 + 模式 + 受众 + 语言」做确定性哈希来选择钩子、示例、活动与目标条数，不依赖 `Math.random` 或时间戳——同一输入两次调用，产出结构完全一致。
