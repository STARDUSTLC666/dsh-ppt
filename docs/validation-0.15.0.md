# 0.15.0 验证记录

验收日期：2026-10-22–23。自动检查、真实 DSH Web、离线 HTML 和最终 PPTX 的证据分开记录。

## 已通过

- Windows / Node 24：180 项测试，包括 29 项数据模式回归检查。覆盖 CSV / TSV、带引号与换行的单元格、材料行 / 百分比、受限算术、循环 / 除零 / 非有限值 / 范围步长、模板分页、更新差异、确认凭证与修订、外部文件改动、复制 / 撤销、浏览器路径限制、参数工程身份及导出备注。
- 普通纯文字生成在故意阻断数据解析依赖的独立进程中仍可用；启用数据绑定时缺依赖会给出安装提示。数据模式不要求模型或 API Key。
- 官方 DSH 0.2.1-rc.2 隔离 Web 宿主，通过原生 `ppt_create` 注册并生成数据工程；八个工具及技能正常加载。启动令牌交换 303、未登录 401、已登录 200。
- 实际浏览器点击数字，从利润追到收入公式，再追到 CSV 单元格；未关联数字给出明确状态。滑杆 / 数值输入、图表与文字联动、非法步长、恢复参数、旧下载拦截均检查。
- DSH 工作台实际替换 CSV：收入 1000→1200、成本 600→650，先显示指标与四页影响，再确认保存副本。原稿保留；副本撤销后恢复数据与绑定。
- 离线 HTML 实际保存参数 JSON，回 DSH 导入、预览和确认；再导入原稿参数到新副本会拒绝。下载的静态 PPTX 包含确认后的收入 1920、利润 1270，与页面结果一致。
- iframe 与外部工作台参数双向联动；非法输入立即提示，预览和下载受保护；伪造来源 / nonce 的消息被忽略。英文深色界面在 390px 下无横向溢出，内容语言保持原文。浏览器无未捕获异常。
- 最终下载的四页 PPTX 用官方 LibreOffice Kit 0.1.5 原生引擎生成 PNG / PDF，没有缺失字体；逐页查看封面、要点、原生图表及表格，核对确认数值和版式。XML / 原生备注检查包含公式、材料定位、来源校验值和假设。
- 修复并复验隐藏幻灯片外框拦截当前页点击的问题。数据面板隔离键盘、滚动和触摸事件；真实触屏设备未测。

Browser 插件在本次环境不可用，使用后台 Playwright / Chrome 访问真实 DSH Web 与本地 HTML；没有切换用户的前台窗口。

## 范围

桌面原生窗口中的新功能逐项点击、Microsoft PowerPoint / WPS 的实际应用渲染未测，不能由 Web 或官方 Kit 通过替代。模型效果不是本次数据功能的验收对象。

本版不直接解析 XLSX / PDF，不监视源文件，不自动寻找或判定来源真实性。HTML / PPTX 保留引用摘录；JSON 保留完整导入材料。

临时宿主、下载、渲染输出和截图在交付收尾中清理；仓库保留永久回归测试。npm 包、CI 与组合包安装另走发布校验，不以本地测试结果代替已发布状态。
